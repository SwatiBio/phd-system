# DAC Meeting Notes — disclosed rules

<!-- Disclosed reference for refine-meeting. Load only when shaping a DAC meeting. -->

A DAC session is a formal, graded, twice-a-year institutional event. Guide notes never carry these
requirements; DAC notes always do.

## Extra fields on top of the Meeting Note template

- **Attendees incl. committee role** — full DAC roster present at the meeting (chair, guide, members)
- **Grading received** — the rubric grade given in the recommendation sheet (excellent → very poor).
  Record it verbatim; the consequences hang on it
- **Annexure 23 pointer** — the meeting minutes are filed on the institutional template by the
  coordinator; the note records *where that filing lives* (physical file at institution + copy sent
  to CDS within 10 days), not the minutes content itself
- **Action items become the next report's plan** — every DAC action item is future "plan for next
  period" material for the Annexure 28 report; tag them so the assembler can find them

## Grading consequences (Section 12, MAHE guidelines)

- **poor / very poor** → progress "not satisfactory": repeat (interim) DAC within 3 months;
  scholarship withheld until DAC recommends continuation
- Two consecutive half-yearly reports missed → registration cancellation + scholarship refund

## Deadline chain baked into every DAC note

1. Report guide-approved → DAC members **7 working days before** the meeting (portal locks)
2. ≥4 members accept → meeting scheduled
3. Approved report + minutes → CDS **within 10 days** of the meeting
4. **Reports never combined** — one per 6-month period, even during extension

## After shaping a DAC note

Remind the user (once, in the report-back line) that the grading + action items now feed the next
progress report draft, and that the guide-signature ritual from the weekly logbook still applies if
the meeting produced new commitments.
